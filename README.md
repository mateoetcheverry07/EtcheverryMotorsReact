# etcheverry motors - trabajo final utn

proyecto final para el curso de desarrollo frontend. es una aplicacion web para una concesionaria de vehiculos maquetada con componentes.

## como ejecutar el proyecto

1. abrir la carpeta del proyecto en vscode.
2. abrir la terminal y correr el siguiente comando para instalar las dependencias necesarias:
npm install

3. levantar el servidor local corriendo:
npm run dev

## caracteristicas y tecnologias

- vite y react
- rutas con react-router-dom
- formulario controlado con usestate (seccion vende)
- renderizado dinamico de listas con map (seccion catalogo)
- estilos en css puro
